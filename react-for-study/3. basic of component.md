# コンポーネント開発(基本)

## コンポーネントを支える基本概念 -PropsとState
### Props/State
 - **Props**:コンポーネントにパラメーターを渡すための引数
 - **State**:コンポーネント内の状態を表す変数
 - コンポーネントでは、Propsで外から値を受け取り、以降は刻々と変化していく状態をStateで管理していく

### Propsの基本
#### Propsのデータ型
- プロパティ名='--'：文字列の場合''で括ることで文字列に見なす
- プロパティ名={--}:数字/配列/関数/オブジェクトの場合{}で括ることで認知する

### イベント処理の基本
- **イベント**:状態を変化させるトリガー
    - ボタンをクリックした
    - 入力値を変更した
    - マウスを動かした
- **イベントハンドラー**:イベントによって呼び出されるコード（関数）

### Stateの基本
- **useState関数：const[state, setState] = useState(initialState)**
    - state:State値を格納する変数
    - setState:State値を更新するための関数
    - initialState:Stateの初期値
    Stateではなく、受け取ったPropsを直接操作することはできない
- **コンポーネントの更新タイミング**
    - Reactでは、以下の場合にコンポーネントを再実行することで再描画している
        - Stateが更新された場合
        - 渡されたPropsが変更された場合
        - 親コンポーネントが再描画された場合
### React Developer Toolsの導入
Props/Stateがアプリ内部でどのように値を受け渡ししているのか、それぞれの値がどのように変化しているのかをリアルタイムに把握することができる
