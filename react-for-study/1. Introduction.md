# 1.Introduction

## 1-1. ReactとJavascript
### AjaxによるJavascriptの復権
- **Ajax**:Asynchronous javascript + XML
- Ecma InternationalによるJavascriptの標準化により、どのブラウザでもJavascriptが利用できる形になった
### HTML5の時代へ
- HTMML5では、Javascript APIが整備されたことでJavascriptのみでできることが多くなった。

## jQueryから新世代のライブラリへ
- **jQuery**:2000年代後半から10年間近くデファクトスタンダードのライブラリ
### jQueryの魅力と限界
- jQueryでは、アニメーションや、Ajax通信、標準Javascriptの拡張などはばひろいUI開発サポートがあるライブラリ
- jQueryでは、入出力の際にページ構造を意識しなければいけない→ページとオブジェクトとの間を取り持つJavascriptライブラリ（フレームワーク）
## 主なJavascriptフレームワーク

※ライブラリとフレームワークの違い
- ライブラリ：ユーザーコードから呼び出されることを想定(ライブラリが自発的に何かをすることはない)
- フレームワーク：ユーザーコードはフレームワークによって呼び出されることを想定。アプリのライフサイクルを管理し、その枠組みの中でユーザーコードに問い合わせする

## Reactの特徴
### 導入ハードル、学習コストが低い
### コンポーネント指向
- **コンポーネント**：ページを構成する部品　ビュー（テンプレート）、ロジック（オブジェクト）スタイルなど
- Reactでは、部品化されたコンポーネントを組み合わせることでページを構成していく
### ドキュメントやライブラリが充実している

## 1-2.Reactアプリを開発/実行するための基本環境
- **Create React App**：Reactアプリを開発するためのコマンドラインツール
    - アプリの骨組みをコマンド一つで作成可能
    - 作成したアプリを実行するためのトランスパイラー、バンドラー、開発サーバー機能も備わっている
        ##### **トランスパイラー**
         - JSX(Javascript XML)などの拡張構文をピュアなjavascriptに変換する機能
         - TypeScriptをJavascriptに変換する機能
         - 代表：Babel
        
        ##### **バンドラー**
         - 大量のモジュールを束ねて転送を行う処理を**バンドル(bundle)**という
         - Create React Appでは、webpackというバンドラーが採用されている
         - ミニフィケーション：コードサイズの最小化(コメント削除,空白削除,ローカル変数名の短縮)
         - ダイジェスト付与：最終的に生成されるファイル名末尾にハッシュ値(ダイジェスト)を付与

        ##### **開発サーバー**
         - サーバー：ネットワーク上に常時待機してコンテンツ・サービスを提供するためのコンピューター
         - HTTPサーバー：HTTP経由でコンテンツを提供するサーバー
         - Create React Appでは、webpack-dev-server
