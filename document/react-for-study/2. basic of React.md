## サンプルアプリの内容確認
- **DOM(Document Object Model)**：HTMLやXMLドキュメントの構造を表現するオブジェクトモデル
    - ブラウザは、ウェブページを読み込む際にHTMLドキュメントを解析し、DOMツリーを生成します。このツリー構造は、ドキュメント内の各要素（タグ、属性、テキストなど）をノードとして表現します。
    - DOMを使用すると、JavaScriptなどのプログラミング言語からウェブページの内容や構造を動的に操作することができます。例えば、要素の追加、削除、スタイルの変更、イベントの処理などが可能
- **レンダリング**：Webコンテンツを画面上に描画すること
- **JSX**：Javascriptの拡張構文で、Javascriptのコードにタグ構造を埋め込むための仕組み
- **仮想DOM**：メモリ上におかれたDOMのコピー
    - 変更された最終結果(差分)だけを適切なタイミングで実際のDOMに書き戻す
    - DOM操作は一般的にオーバーヘッドが大きな処理のため、これによって更新の範囲も頻度も最小限に抑えてパフォーマンスを改善している

## JSXの基本
#### JSXのルール
- **Javascriptのコード内にHTMLさながらのタグを埋め込む**
    - 複数の要素を列挙することはできない <br>
    Ex)
    
    ```javascript
    root.render(
        <p>こんにちは、世界！</p>
        <p>はじめまして、React</p>
    )
    ```
    
    ↓

    ```javascript
    root.render(
        <div>
            <p>こんにちは、世界！</p>
            <p>はじめまして、React</p>
        </div>
    )
    ```
    - divタグでなくても **<React.Fragment>**でも良い
        - <React.Fragment>は、複数の要素を束ねるだけの形式的な要素
        - <React.Fragment>を省略して、 <>~</>でも問題ない
    - **空要素は「~/>」で終える**
    ```javascript
    const tag = <img src={image} />; //●
    const tag = <img src={image}>;  //Unterminated JSX contents
    ```

    - **名前の異なる属性がある**
        - HTMLのtabindex⇒JSXのtabIndexのようにキャメルケースになる
        ```javascript
        const input = (
            <div className="field">
                <label htmlFor="title">書名</label>
                <input id="title tabIndex="2" />
            </div>
        );
        ```

    - **JSXのコメント構文は3種類**
        - // ~
        - /* ~ */
        - {/* ~ */}
    ```javascript
    const tag = (
        //コメント（JSX式内でないのでOK）
        <ul>
        {/*コメント*/}
            <li //タグ内ではOK>
            >React</li>
            <li /*この記法も問題ない*/>Vue.js</li>
        </ul>
    )
    ```
#### JSXにJavascript式を埋め込む - {…}構文
- JSX式には、{…}の形式で任意にJavascript式を埋め込むことが可能
- {…}構文では式はエスケープ処理される
    - 脆弱性の一因になるため。(ユーザーがスクリプトを混入させた際XSSを行うことができる)
    - 動的にHTML文字列を生成し、ページに反映させたいケースでは
    ```javascript
    <p dangerouslySetInnerHTML={{__html: content}}></p>
    //dangerouslySetInnerHTML属性の__htmlキーd指定されたテキストは、エスケープされずにそのまま要素配下に埋め込まれる
    ```
- 実体参照の埋め込みに注意
```javascript
root.render(
    <div>{'Tom &amp; Jerry'}</div>
);

//Tom &amp; Jerry
```
実体参照をしたい場合
```javascript
<div>{'Tom \u0026 Jerry'}</div> //エスケープシーケンス
<div>{`Tom ${String.fromCodePoint(38)} Jerry`}</div> //Unicodeコードポイントから取得
<div dangerouslySetInnerHTML={{__html: 'Tom &amp; Jerry'}}</div> //エスケープ抑制
```
- 注意：bool値, Undefined/nullは無視される
    - {…}構文でのtrue/false, undefined/null値はすべて出力されない⇒String(…)にしてString型として表現

#### {…}構文で属性を設定する
```javascript
const dest = 'https://ja.react.dev';
root.render(
    <a href={dest}>React本家サイト</a>
);
//<a href=https://ja.react.dev>React本家サイト</a>
```
- 複数の属性をまとめて設定する
```javascript
const attrs = {
    href: `https://wings.msn.to/`,
    download: false,
    target: `_blank`,
    rel: `help`
};
//見通しが悪いコード例
root.render(
    <a href={attrs.href} download={attrs.download} target={attrs.target} rel={attrs.rel}>サポートページ</a>
);

//見通しが良いコード例
root.render(
    <a {...attrs}>サポートページ</a>
);
```
- 属性値の既定値はtrue

#### スタイルシートを設定する -Style 属性
- {…}構文では式の値を文字列として渡すのが一般的だが、style属性だけは例外
```javascript
//文字列として渡すことはできない
const props = 'color: White; background-color: Blue; padding: 3px;
root.render(
    <p style={props}>WINGSプロジェクト</p>
);

//オブジェクト形式で引き渡す
const props = {
    color: 'White',
    backgroundColor: 'Blue',
    padding: 3
};

root.render(
    <p style={props}>WINGSプロジェクト</p>
);
```
- 名前はキャメルケース
- 数値の単位はpxが規定
- スタイルの指定はclassName属性が基本

#### JSX式の実体を理解する
JSXをJavascript本来のコードに書き換える
- **createElement(tag [,props [,...children]])**
    - tag:タグ名
    - props:属性(「名前：値, ...」形式)
    - children:子要素群（可変長配列）
